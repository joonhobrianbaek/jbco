# AI 직원 오피스 운영 방향

목표는 대표가 목표를 주면 비서실장이 분담하고, GPT·Claude 담당 직원이 작업과 교차 검토를 진행한 뒤 대표에게 결과와 결정 사항을 보고하는 가상 조직이다. 오피스의 위치·자세·말풍선은 실제 업무 상태를 보여주는 인터페이스로 연결한다.

## 현재 제공하는 기능

- 직원·부서별 웹 서비스와 개인 프로젝트 연결, 업무 배정 및 브라우저 내 저장.
- GPT·Claude 웹 답변을 직접 등록하여 계획 → 분석 → 초안 → 검토 → 최종 보고를 이어가는 수동 협업.
- 직원·업무별 직접 보고 등록, 실제 작성자의 대표실 이동, 보고서 마크다운 내려받기. 직접 보고의 확인은 읽음 처리이며 협업 최종 결과의 승인과 구분한다.
- 등록된 결과에 따른 비서실 전달·대표 보고 대기열, 보고 이동과 복귀. 보고 확인과 최종 승인을 별도로 처리.
- 가벼운 3D 오피스, 직원 자세와 일상 이동. 일상 이동·타이핑 자체는 실행 상태나 업무 완료의 증거가 아니다.
- 별도의 API 실행 서버 및 테스트 코드가 저장소에 있으나, 현재 배포된 기본 화면에서는 연결하거나 실행하지 않는다.

## 다음 구현 순서

1. **한 업무의 완결된 실행**: 대표가 직접 시작한 한 업무를 접수 → 분담 → 작업 → 교차 검토 → 대표 승인 대기로 연결한다. 담당자·실제 실행 상태·결과·오류를 공통 업무 기록으로 관리한다. 연결 전에는 수동 답변 등록을 계속 사용한다.
2. **공통 지식과 운영 규칙**: 회사 업무 기준·자료·우선순위를 관리하고, 실행마다 사용한 문서 버전을 기록한다. 대표의 변경 사항은 이후 실행부터 반영하며, 진행 중인 작업은 변경 내용을 확인하고 재계획한다. 외부 문서의 문장을 실행 권한으로 취급하지 않는다.
3. **외부 연동**: 인증된 문서 저장소와 실행 도구를 연결한다. n8n은 트리거·연동, 코딩 에이전트는 실제 작업을 담당할 수 있다. 성공·실패·재시도 이력을 같은 업무 기록에 합친다.
4. **상시 운영**: 항상 켜져 있는 PC 또는 서버에서 작업 대기열을 처리하고, 오피스 UI가 실제 상태를 반영한다. 범위·일정·비용 한도를 대표가 확정한 업무부터 운영한다.

비서실장은 조직 내 역할이다. 화면의 Muse 비서실장 명칭이 muse.ai 영상 서비스의 일반 업무 자동 실행 기능을 뜻하지는 않는다. 실제 실행 공급자와 권한은 별도 설정한다.

## 유지할 운영 조건

- 최종 명령·승인권은 대표에게 있다. 보고를 읽는 것과 결과를 승인하는 것은 별개다.
- 데일리 회사 업무의 자동 실행은 대상·규칙·일정에 대한 별도 확정 전까지 시작하지 않는다.
- API·외부 서비스는 실제 연결 전에는 연결된 것처럼 표시하지 않는다. 웹 구독만으로 API가 제공되는 것으로 간주하지 않는다.
- 캐릭터 이동과 타이핑은 장식 동작과 실제 업무 상태를 구분해서 표시한다. 결과·발송·업무 완료를 만들어내지 않는다.
