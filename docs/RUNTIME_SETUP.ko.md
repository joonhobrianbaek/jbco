# BB Office 자동 업무 서버 연결

[Render에서 서버 배포 열기](https://render.com/deploy?repo=https%3A%2F%2Fgithub.com%2Fjoonhobrianbaek%2Fjbco)

저장소의 `render.yaml`이 Node 서버 1개와 업무 기록용 1GB 영구 디스크를 설정합니다. **Starter 유료 서버와 디스크 요금이 발생합니다. GPT·Claude API 사용료는 별도입니다.** 실제 금액은 Render의 생성 화면에서 확인한 후 생성하세요. 무료 서비스는 비활성 시 대기 상태가 되고 이 구성의 영구 디스크를 제공하지 않아 선택하지 않았습니다. 현재 호스팅 계정 생성·결제·서버 생성은 아직 수행되지 않았습니다.

## 1. 계정 연결과 서버 생성

1. 위 링크에서 Render에 로그인하고 필요한 경우 GitHub 저장소 접근을 연결합니다.
2. `joonhobrianbaek/jbco` 저장소의 `main` 브랜치와 Blueprint 내용을 확인합니다. 서비스는 `bb-office-runtime`, 인스턴스는 1개입니다. 다중 인스턴스로 늘리지 마세요. 현재 업무 실행 잠금은 단일 서버 기준입니다.
3. 아래 비밀 환경변수를 입력합니다. 키를 채팅이나 GitHub 파일에 붙여넣지 마세요.

| 환경변수 | 등록할 값 |
| --- | --- |
| `OPENAI_API_KEY` | 본인 OpenAI API 프로젝트의 키 |
| `ANTHROPIC_API_KEY` | 본인 Anthropic Console의 API 키 |
| `OPENAI_MODEL` | 본인 OpenAI API 계정에서 사용 가능한 텍스트 모델 ID |
| `ANTHROPIC_MODEL` | 본인 Anthropic API 계정에서 사용 가능한 Claude 모델 ID |

키 발급: [OpenAI API](https://platform.openai.com/api-keys), [Anthropic Console](https://console.anthropic.com/). ChatGPT·Claude 웹 유료 구독만으로 API 사용료가 충당되지는 않습니다. 각 API 프로젝트의 사용 한도도 설정하세요. 모델 ID는 웹 서비스 표시 이름과 다를 수 있습니다.

4. 비용과 설정을 검토하고 생성합니다. Render가 HTTPS 주소를 발급하고 Node 서버를 실행합니다. `/healthz`는 키 없이 서버·저장소 준비 여부만 반환하며, 업무 내용과 설정은 공개하지 않습니다.
5. 서비스 화면에서 공개 HTTPS 주소를 복사합니다. 예시는 `https://bb-office-runtime-xxxx.onrender.com`이고, 실제 발급 주소를 사용해야 합니다.
6. 서비스의 Environment에서 자동 생성된 `OFFICE_RUNTIME_TOKEN` 값을 복사합니다. 이 값은 대표 승인 권한도 포함하므로 공유하지 마세요. API 키와 다른 값입니다. 화면에서 기존 값을 볼 수 없다면 충분히 긴 임의 토큰으로 교체하고 재배포하세요.

## 2. 오피스에서 연결

1. [오피스 열기](https://joonhobrianbaek.github.io/jbco/?v=office17).
2. 오른쪽 `자율 업무` → `실행 서버 연결`을 엽니다.
3. 실행 서버 주소에 발급된 **HTTPS 주소**, 서버 연결 토큰에 `OFFICE_RUNTIME_TOKEN`을 입력합니다. OpenAI·Anthropic 키는 이 화면에 넣지 않습니다.
4. `연결 확인` 후 `GPT·Claude 자동 작업 가능` 표시를 확인합니다.
5. 짧고 민감하지 않은 업무로 시작합니다. 예: “제공 자료: A안 비용 100, B안 비용 120. 두 안을 비교하고 추가 확인 항목을 정리해줘.”
6. 업무 분담 → 직원별 결과 → 교차 검토 → 대표 보고를 확인하고 `대표 승인` 또는 `수정 지시`를 누릅니다. 이 단계부터 실제 API 사용료가 발생합니다.

서버 주소만 브라우저에 저장합니다. 연결 토큰은 페이지 메모리에만 있어 새로고침하면 다시 입력해야 합니다. 브라우저를 닫아도 실행 중 업무는 서버에서 계속 진행합니다. 서버를 재배포하면 실행 중 업무는 중단 상태가 되며 자동 재실행하지 않습니다. 영구 디스크에 완료된 결과·부분 결과가 남습니다. 중요한 업무 중에는 재배포를 피하세요.

## 연결이 안 될 때

- 서버가 열리지 않음: Render의 배포 상태와 로그를 확인하세요. `.env` 파일 업로드는 필요하지 않습니다.
- `/healthz`가 503: 영구 디스크 경로·쓰기 권한 또는 저장된 기록 읽기 오류를 확인하세요.
- “서버에 허용된 오피스 주소가 아닙니다”: `OFFICE_ALLOWED_ORIGINS`가 `https://joonhobrianbaek.github.io`인지 확인하세요. 끝에 `/jbco/`나 슬래시를 붙이지 않습니다.
- 인증 오류: 서버 연결 토큰을 다시 입력하세요. 토큰 변경 후에는 열린 탭에도 새 값을 입력해야 합니다.
- API 키 또는 모델 설정 필요: 위 네 환경변수가 비어 있지 않은지 확인하세요.
- AI 서비스 응답 401/403: API 키 권한을 확인하세요. 400/404: 모델 ID와 API 지원 여부를 확인하세요. 429: API 사용 한도·결제 상태를 확인하세요.

이 서버는 단일 대표용입니다. 모든 보고서 열람·업무 생성·최종 승인은 하나의 서버 토큰으로 보호됩니다. 사용자별 로그인은 포함하지 않습니다. 승인 버튼은 결과 확정 기록이며 실제 외부 발송·결제·제출·배포를 실행하지 않습니다. 작업마다 최대 12회 API 호출, 응답당 최대 1,800토큰, 대표 수정 최대 2회이며 이 제한은 금액 기준 예산 제한은 아닙니다.
