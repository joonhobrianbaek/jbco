# PC에서 가상 AI 업무 실행

1. ZIP을 압축 해제하고 START_BB_OFFICE.cmd를 실행합니다. Node.js 20 이상과 로그인된 Codex/Claude CLI가 필요합니다.
2. 고정 가상 청구 입력을 Codex가 분석하고 Claude가 검토합니다. 실행기가 별도로 정수 합계를 대사합니다.
3. BB Office의 작업 폴더 버튼에서 사용자 홈의 BB_Office_Demo_CLI/jobs 폴더를 선택합니다.
4. 상태가 대표 승인 대기인지 확인하고 원본 JSON 결과를 검토합니다. 최신 사이트에서는 검증된 가상 CLI 업무에 한해 승인/수정 요청이 즉시 상태에 반영됩니다. 실행기를 다시 켤 필요가 없습니다. 외부 제출은 없습니다.

동일 입력은 다시 실행하지 않습니다. 실패 원인을 해결한 뒤 명시적으로 재시도할 때만 `node scripts/run-cli-demo.mjs --retry`를 실행합니다.
실행 중 강제 종료하면 잠금 폴더가 남을 수 있습니다. 원래 CLI 프로세스가 끝났는지 확인하기 전 잠금을 지우지 마세요.

Codex는 read-only sandbox로 실행합니다. Claude는 내장 도구와 MCP 도구를 비활성화합니다. 프롬프트는 표준입력으로 전달하며 비밀정보를 소스나 사이트에 넣지 않습니다. 회사 파일·업무 일정은 연결하지 않습니다.
CLI는 기존 로그인 계정을 사용합니다. 화면에서 확인된 Claude 계정은 회사 Team 계정입니다. 실제 사용량·계정 정책은 해당 서비스 설정을 따릅니다.

검증 범위: 이 개발 환경에는 두 CLI가 없으므로 실제 모델 호출과 Windows 실행은 아직 미검증입니다. 테스트는 주입한 응답으로 중복 방지·실패·합계 대사·동시 실행을 확인합니다.

## Windows 실행 오류 수정
ZIP은 반드시 모두 압축을 푼 뒤 실행합니다. Windows CLI 래퍼의 인자 전달을 수정했습니다. 기존 실패 기록이 있으면 `RETRY_FAILED_JOB.cmd`를 한 번 실행하세요. 완료된 업무는 재실행하지 않습니다. 실패 시 제한된 진단 메시지를 표시하며 일반적인 토큰 형태는 가립니다. 오류를 공유하기 전 개인정보가 없는지 확인하세요.

## 사이트의 폴더 기억과 승인
처음 한 번 jobs 폴더를 연결하면 이 브라우저의 IndexedDB에 폴더 핸들만 저장합니다. 다음 접속 시 읽기 권한이 유지되어 있으면 자동으로 복원합니다. 권한이 만료되면 저장된 폴더 다시 연결을 누르세요. 다른 브라우저, 비공개 창, 사이트 데이터 삭제 후에는 다시 선택해야 합니다. 연결 해제는 저장된 핸들도 지웁니다. 파일은 서버에 전송하지 않습니다.
승인 즉시 반영은 local-cli-synthetic-v1 고정 가상 업무에만 적용합니다. 입력/규칙/결과 해시, Codex·Claude 금액과 검토 결과를 검증한 뒤 명시적 사용자 결정만 기록합니다. 일반 업무의 실행기 규칙은 변경하지 않습니다. 상세 합계와 분석·검토 내용은 작업 폴더 화면에서 확인할 수 있습니다.
