# 로컬 폴더 연결과 가상 업무 승인 개선

- 폴더 핸들을 브라우저 IndexedDB에 보관하고 다음 접속 시 권한을 조회해 복원합니다. 권한 요청은 사용자가 재연결을 누를 때만 수행합니다.
- 폴더 설정 저장 실패, 권한 만료와 읽기 실패를 구분해 표시합니다. 해제하면 저장된 핸들도 지웁니다.
- 가상 CLI 업무는 입력/규칙/작업 ID/결과 SHA-256과 독립 BigInt 합계를 확인한 뒤 사이트의 명시적 승인으로 상태를 반영합니다. 모델을 호출하지 않습니다.
- 일반 실행기 업무는 기존 decision 기록 계약을 유지합니다.
- 사이트에서 합계, 검증 상태와 분석·검토 내용을 확인할 수 있습니다.

## 검증
Node 전체 테스트 79개 통과. CLI 결과 fixture로 브라우저 승인·수정 요청·변조 차단을 검증했습니다. 권한 granted/prompt/denied, 저장 없음·잘못된 핸들·저장소 미지원의 복원 동작을 확인했습니다. 기존 파일 변경 및 중복 결정 차단 테스트도 통과했습니다.
브라우저 미리보기 접근이 환경 정책에 의해 차단되어 실제 File System Access API와 IndexedDB 핸들 직렬화, 새 접속 권한 유지 여부 및 화면 배치는 미검증입니다. 사용자 PC에서 확인이 필요합니다.

## 제한
같은 브라우저와 사이트에서만 핸들을 복원할 수 있습니다. 사이트 데이터 삭제나 비공개 창은 폴더를 다시 선택해야 합니다. 브라우저의 권한 정책은 우회하지 않습니다. 회사 실제 자료, 운영 일정과 백그라운드 실행은 활성화하지 않았습니다.
