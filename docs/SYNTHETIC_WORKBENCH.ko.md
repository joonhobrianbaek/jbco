# 가상 업무 실행실

사이트 상단의 가상 업무 실행 버튼에서 고정 가상 입력 3종을 실행한다.
입력 접수, 코드 계산, 독립 BigInt 대사, 대표 승인/수정, 실행 근거 JSON 저장을 연결했다.
AI 호출은 하지 않는다. 브라우저 저장소의 개별 기록이며 외부 데이터나 일정을 사용하지 않는다.

- 정상: 2 × 1,250 + 3 × 500 = 4,000센트, 원본 대조 합계와 일치, 대표 승인 대기.
- 자료 누락: 단가와 원본 합계 확인 전 계산 성공으로 처리하지 않는다.
- 합계 불일치: 계산 100센트, 대조 200센트로 실패한다.

동일 입력·규칙 버전의 ID는 SHA-256으로 고정한다. 반복 버튼 클릭은 기존 결정과 결과를 보존한다.
승인은 jobId/inputVersion/ruleVersion에 결합하며, 입력·규칙·결과를 다시 검증한다.
같은 결과에 두 번 승인하거나 검증 실패 결과를 승인할 수 없다. 수정 요청은 자동 재작성하지 않는다.
실행 기록에서 AI 호출 없음과 browser-code 실행기를 표시한다.

Notion 보고는 연결된 대화 도구로 한 차례 반영했다. 개인 페이지 주소·ID는 공개 소스에 넣지 않는다.
사이트에서 승인해도 Notion은 자동 변경되지 않는다. GPT·Claude CLI/API 인증이 없어 실제 AI 실행은 미연결이다.
기존 runtime/agents.mjs의 API 실행은 별도의 인증 서버가 필요하며 정적 Sites 배포에서 실행되지 않는다.

검증: 정상 계산, 누락, 합계 불일치, 변조, 이중 승인, 수정 사유, 허용되지 않은 입력,
SHA-256의 빈 문자열/다중 블록/한글·이모지를 Node 기준값과 대조했다.
브라우저의 2D 모드에서 정상 입력 버튼의 실제 $40.00 계산과 대표 승인 대기를 확인했다.
